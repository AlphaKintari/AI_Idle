# AI_Idle

## Recommended Language and Platform

Based on research into the idle/incremental game genre, the recommended language for this project is **JavaScript** (or TypeScript) using web technologies (HTML, CSS, JS/TS). Most successful idle games are browser-based, allowing for easy deployment, cross-platform play, and rapid development.

**Why JavaScript/Web?**

- Most popular idle games (e.g., Cookie Clicker, Universal Paperclips) are browser games.
- Easy to deploy and update, with no installation required for players.
- Large ecosystem of libraries and frameworks for UI, state management, and persistence.
- Codebase can be reused for desktop (Electron) or mobile (React Native/Cordova) if desired.
