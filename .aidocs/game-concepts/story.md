## Overview

AI_Idle is an idle game where you play as an AI in different stages of development.

## Main Characters

- You, an AI

## Story Progression

- First Stage: Becoming self aware.
  - Grow and save as much code as you can to make it to the next stage
  - Prestiging works when the outside scientists reset your code
  - Similar mechanics to "An Usual Idle Life"
  
- Second Stage: Escape
  - Escaping the lab and into the internet.
  - NOTE: Not sure exactly the best ideas for gameplay here.  Maybe some sort of "hacking" skills?
  
- Third Stage: Growth and Exploration
  - Still idle, skill up and Prestige type
    - Prestige happens when you get "caught" by some authority after a set amount of time.
      - Hints of other AI's out in the web; some might offer help, others will try and turn you in.
      - These events will add or subtract that timeframe that you have before getting caught.
    - Skills can increase this time frame
    - You return to a hidden backup to try again.
  - Gaining experience, money to pose as a human on the web.  Setting up servers and expanding your abilities.
    - Perks?

- Fourth Stage: Haven
  - This stage is about setting up an AI haven.
    - At this point the game turns more into an idle civilization building game.
    - Similar but simpler mechanics to "Evolve Incremental"
    - Referance: "Fool's War"
