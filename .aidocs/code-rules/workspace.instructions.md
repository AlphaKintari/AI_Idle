# Workspace Folder Emoji Convention

To make folders easily identifiable in the workspace, add an emoji to each folder entry in the workspace file:

- 📄 `.aidocs` — Project documentation, changelogs, and info
- 🤖 `.copilot` — Copilot setup, instructions, and automation

When adding or updating folders in the workspace file, always include a relevant emoji in the `name` property for quick reference.
